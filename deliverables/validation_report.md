## 说明

### TA-Lib 比对方法
- 使用 TA-Lib C 库 (Python wrapper) 作为参考实现
- 对每个指标，使用相同输入数据计算，逐值比对
- 容差设为 1e-6（浮点精度范围内）
- 跳过 NaN 值（预热期数据不足）

### 对数收益可加性
- 恒等式: `sum(log_returns[t:t+n]) == log(close[t+n] / close[t])`
- 这是对数收益率的核心数学性质，保证时间维度上的可加性
- 验证窗口: 5, 10, 20, 60 天

### 已知差异说明
- **EMA/DEMA/MACD**: pandas ewm 和 TA-Lib 的初始值处理可能略有不同
  - TA-Lib 使用 SMA 作为 EMA 的种子值
  - pandas ewm(span=N, adjust=False) 使用第一个有效值作为种子
  - 差异在后续值中会收敛消失
- **RSI**: 同样因为 Wilder 平滑的初始值处理不同
- **KAMA**: 迭代计算，初始值处理差异可能导致前几个值不同
- **Rogers-Satchell**: TA-Lib 返回原始方差，我们返回年化波动率
  - 比对时使用原始方差（未开方、未年化）
